F350 PID SCANNER

Not connected

1 — STANDARD PIDS (fast, ~10s)

Asks the ECU which Mode 01 PIDs it supports, then reads each one.

2 — FIND MODULES

Pings known Ford module addresses to see which answer.

3 — MODE 22 SWEEP

Slow. 0000-FFFF on one module is ~1.5h. Start with a narrow range.

4 — SNAPSHOT & DIFF ← use this for 4WD

Snapshot A, change the truck (4H→4L, lock the diff, flip an upfitter), snapshot B, then DIFF. Only PIDs whose value changed are listed.
